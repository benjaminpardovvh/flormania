# FlorManía

## Archivos
- `index.html`: estructura HTML.
- `css/style.css`: estilos y diseño adaptable.
- `js/script.js`: interacciones indicadas en la maqueta.

## Funciones implementadas
1. Al pasar el cursor sobre **Envía Flores**, el texto cambia a **Envía Bouquets**; al retirar el cursor, vuelve al original.
2. Al hacer clic en **Iniciar Sesión**, aparece una alerta: `Bienvenido a la tienda de flores`.
3. Al hacer clic en **Comprar**, desaparece ese botón.
4. **Ver más Flores** muestra u oculta productos adicionales.
5. Las categorías filtran los productos.

## Ejecutar
Abre `index.html` en un navegador. Las fotografías se cargan desde URLs de Unsplash, así que se necesita conexión a Internet para verlas.
